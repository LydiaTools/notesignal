# Design decisions

**Concept:** an annotated field notebook, not an analytics dashboard. Research is a deliberate series of page observations. The narrow popup reads like a marginal note: a red spine, one action, then an editable record.

**Palette:** paper `#f8f7f2`, ink `#26333a`, signal red `#b94a42`, field blue `#477887`, quiet line `#c9cfc8`.

**Type:** Georgia for the product name and key section titles; Arial and system Chinese sans-serif for controls and small records.

**Layout:** masthead and three tabbed work surfaces. Capture is a single sequence, library is a compact ledger, brief is a plain editable text source. At mobile popup widths, the layout fills available width.

**Differentiator:** the red margin spine marks the page-to-insight transition. It does not use simulated “viral” analytics or fabricated content screenshots.

**Known limits:** Chrome extension popups are not full mobile apps. Selectors are best effort and need human correction after platform layout changes.
